## 🧠 Overview

Gold Price Prediction is a machine learning project that aims to predict the future price of gold based on historical price trends and financial indicators such as inflation, USD index, interest rates, and crude oil prices.

This project can be useful for:
- Financial analysis
- Investment decision support
- Market trend forecasting
